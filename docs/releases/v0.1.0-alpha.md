# Madrasa Lite v0.1.0-alpha

First pre-release for testers. Built from `main` at the end of milestone M1 (Stages 1–7):
school setup, students and guardians, fees (structure, sibling discounts, concessions,
vouchers, receipts, late fees, defaulters, collections), attendance (sections, staff,
calendar, registers), exams (assessments, mark sheets with approval, report cards),
encrypted nightly backup and restore, Excel/CSV import and export, year rollover, dashboard,
English and Urdu.

**Installers are unsigned.** Windows shows "Windows protected your PC": click *More info*,
then *Run anyway*. See `TESTING.md` for installation, setting up a test school, loading the
sample data and a list of things to try.

**Assets**

- `Madrasa_0.1.0_x64-setup.exe` — Windows 10/11
- `Madrasa_0.1.0_amd64.deb` — Ubuntu, Debian, Mint
- `Madrasa_0.1.0_amd64.AppImage` — other Linux
- `TESTING.md` — the tester guide
- `sample-students.xlsx`, `sample-staff.xlsx` — made-up data for the import wizard

**Known limits in this build**

- No "load demo school" inside the app; the sample spreadsheets stand in.
- The app does not show its version number.
- Automatic late fees (#9) and schools outside Pakistan (#10) are not in this build.

**Report problems:** https://github.com/quietbytehq/madrasa/issues
